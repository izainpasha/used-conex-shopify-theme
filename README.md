# Used Conex — WordPress to Shopify, built from Figma

Shopify theme for a shipping-container sales and rental business, migrated off WordPress.

![Used Conex — WordPress to Shopify, built from Figma](.github/screenshot.webp)

**Live site:** https://usedconex.com  
**Portfolio:** https://izainpasha.github.io

## The problem
Move a container business from WordPress to Shopify without losing its pages or search rankings.

## What I built
Every page rebuilt from Figma on Dawn. 58 city landing pages run on one metafield-driven location template. GSAP and Lenis add motion, and type is fluid with clamp().

## Result
All 58 city pages, reviews and the blog template are live; service and grade pages verified on the build.

## Stack
Liquid · Dawn · Metafields · GSAP · Lenis
